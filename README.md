Entry for make.fun's ["One-Line Office Joke Laugh-Off"](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) bounty.

## The joke

> Our team building exercise was trust falls — I fell, nobody caught me, and HR called it 'an opportunity for growth'.

## How it works

`main.py` (Python 3, stdlib only) writes the one-line joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout. It validates the entry first: 1–200 characters, not only whitespace, and a single line.

## Run

```bash
python3 main.py
```

To write the output to a custom directory:

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
